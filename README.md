# Computer Tech Help — website

A single-page site for the tech support flyer, ready to deploy on GitHub Pages.

## Files
- `index.html` — the page
- `style.css` — all styling
- `assets/portrait.png` — your photo

## Deploy with GitHub Pages (no coding required)

1. **Create a repository**
   - Go to [github.com/new](https://github.com/new)
   - Name it anything, e.g. `tech-help-site`
   - Set it to **Public**, then click **Create repository**

2. **Upload the files**
   - On the new repo's page, click **Add file → Upload files**
   - Drag in `index.html`, `style.css`, `README.md`, and the whole `assets` folder
   - Click **Commit changes**

3. **Turn on Pages**
   - Go to **Settings → Pages** (left sidebar)
   - Under "Build and deployment," set **Source** to **Deploy from a branch**
   - Set **Branch** to `main` and folder to `/ (root)`, then **Save**

4. **Visit your site**
   - Give it a minute, then refresh the Pages settings page — it'll show your live URL, something like:
     `https://yourusername.github.io/tech-help-site/`

## Making changes later
Edit `index.html` (text/content) or `style.css` (colors/layout) directly in GitHub — click the pencil icon on the file, edit, and commit. The live site updates automatically within a minute or two.
